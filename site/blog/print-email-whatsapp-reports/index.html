Print, export, e-mail and WhatsApp reports from TallyBook

Techardent Labs · 3 November 2026 · 5 min read
Quick answer: Open the report or voucher, then press Alt+P (or Ctrl+P) to print or save it as PDF through your computer's print dialog, Ctrl+E to save the table as a CSV file, or Alt+M to share it. E-mail opens your mail app and WhatsApp opens a chat with a summary of the report already typed; if you choose CSV, TallyBook saves the file and you attach it yourself.

Sooner or later every report leaves the computer: a ledger statement for a customer, the Trial Balance for your CA, the Day Book for a partner. TallyBook gives you three ways out, on the same keys as TallyPrime: print, export and share. Each works on the report or voucher currently on screen.

Print and preview (Alt+P)

Press Alt+P on any report or voucher. The Print menu offers:

OptionKeyWhat it does
CurrentU (or Ctrl+P directly)Prints what is on screen
OthersOMulti-account printing: listed, not available yet
ConfigurationNPrinter settings
  1. Open the report, for example the Day Book, and set the period with Alt+F2.
  2. Press Ctrl+P. The Print screen shows the period, report type, printer and number of copies.
  3. Press I for a preview, or C to configure the printer and copies (1 to 99).
  4. Press P or Enter to print. Your computer's print dialog opens.
  5. Choose a printer, paper size and orientation there, or choose the PDF option to save a PDF file.

If nothing printable is open, TallyBook says “Open a report or voucher to print it”. Digital signatures on printouts are not available yet.

Export as CSV (Ctrl+E)

Press Ctrl+E on any screen with a table. TallyBook asks where to save and writes a .csv file named after the report, which opens in Excel, LibreOffice or Google Sheets. Every visible column is included, so set up the report first: choose the period, use F12 to show or hide columns, Alt+F1 for detail, and Ctrl+F to filter rows. On the Trial Balance and Group Summary, Alt+E also exports CSV; elsewhere Alt+E opens the data Export screen.

CSV is plain text, which keeps it simple and universal. Native .xlsx export is not available yet.

Share by e-mail (Alt+M › E-mail)

Press Alt+M for the Share menu, then Current (R) under E-MAIL, or press Ctrl+M directly.

  1. Choose E-mail from. The first time, create a profile with your sender name and address.
  2. Type E-mail to; separate several addresses with commas.
  3. Check the Subject (the report title is filled in) and add a message if you like.
  4. Press C to choose what goes in: Show Company Name, Show GSTIN/UIN, and Attach report as CSV file (on by default).
  5. Press M. If CSV is on, TallyBook first asks where to save the file.
  6. Your default mail app opens with the address, subject and a text summary of the report. Attach the saved CSV file yourself, then send.
Be clear about what happens: TallyBook does not send the e-mail and cannot attach files to it. It prepares the message in your own mail app; the body even reminds you which file to attach. Long reports are shortened in the body, so rely on the CSV for full figures.

Share on WhatsApp (Alt+M › WhatsApp)

From the Share menu choose Current (C) under WHATSAPP, or press Ctrl+Alt+W.

  1. Enter WhatsApp to: one or more mobile numbers with country code, separated by commas.
  2. Choose File Format: Text (Summary message), or CSV, which also asks for a file name.
  3. Press I to preview the message, then W.
  4. WhatsApp opens a chat for each number with the summary typed in. If you chose CSV, the file has been saved on your computer: attach it in the chat, then send.

Template management, an inbox and WhatsApp configuration appear in the menu but need a WhatsApp Business account and are not available.

Frequently asked questions

Does TallyBook send e-mails by itself?

No. It opens your default mail application with the address, subject and a text summary filled in. You review and send it from there. The SMTP fields in an e-mail profile are saved for later but not used to send mail today.

Why is the e-mail text cut short?

Mail links have a length limit, so long reports are summarised and end with “…”. Turn on Attach report as CSV file in Configure (C) to send the complete data as an attachment.

How do I make a PDF?

Press Alt+P › Current, then P to print. In your computer's print dialog choose Save as PDF (macOS and Linux) or Microsoft Print to PDF (Windows).

Can I print all ledger accounts in one go?

Not yet. Others (multi-account printing and sharing) lists Cash Book, Bank Book and ledger options, but they are not available in this preview. Print each ledger separately.

Try it on your own books. TallyBook is free for Windows, macOS and Linux, with no registration. Download TallyBook and press F1 inside the app for the shortcut list.
