How to install on Windows

  1. Click Download for Windows above. Your browser saves a file named like TallyBook_x64-setup.exe in your Downloads folder.
  2. Open the Downloads folder and double-click that file.
  3. If a blue window says "Windows protected your PC", click More info, then Run anyway. This appears because TallyBook is new and its installer is not yet signed with a paid certificate. It is safe to continue.
  4. Click Next, then Install. It takes under a minute.
  5. Open TallyBook from the Start menu or the desktop icon.

How to install on Mac

  1. Click Download for Mac above. A file named like TallyBook_universal.dmg appears in Downloads.
  2. Double-click it. A window opens showing the TallyBook icon and an Applications folder.
  3. Drag the TallyBook icon onto the Applications folder.
  4. Open Applications, right-click (or Control-click) TallyBook and choose Open. Click Open again in the message. You only need to do this the first time.
  5. If macOS still refuses, open System Settings → Privacy & Security, scroll down and click Open Anyway next to TallyBook.

How to install on Linux

  1. AppImage (any distribution): download it, right-click the file → Properties → Permissions → tick Allow executing as program, then double-click. Or run chmod +x TallyBook*.AppImage && ./TallyBook*.AppImage.
  2. Ubuntu / Debian: download the .deb and run sudo apt install ./TallyBook*.deb.
  3. Fedora / RHEL: download the .rpm and run sudo dnf install ./TallyBook*.rpm.

After installing

  1. TallyBook opens on Company Creation. Type your business name, state and financial year, press Enter through the fields and Ctrl+A to accept.
  2. Already on Tally? Follow Switching from Tally to TallyBook to bring your ledgers and vouchers across.
  3. Press F1 any time for the list of keyboard shortcuts.

Updates

TallyBook checks for a new version a few seconds after it opens. When one is available it asks "Update now ?". Choose Yes and it downloads, installs and restarts on its own. Your company data is kept. You can also press F1 then Alt+U to check by hand. New features arrive on the first Monday of each month; GST and TDS rule changes are released as soon as they are notified.

Common questions

Is TallyBook really free?

Yes. There is no licence fee, no yearly renewal and no feature locked behind payment.

Where is my data stored? Is it uploaded anywhere?

Your company data stays on your own computer. Nothing is uploaded. Use Alt+Y → Backup to save a copy to a pen drive or cloud folder of your choice.

Windows says "Windows protected your PC". Is it a virus?

No. Windows shows this for new programs that are not yet signed with a paid code-signing certificate. Click More info then Run anyway. Signed installers are planned.

Mac says the app "cannot be opened because the developer cannot be verified".

Right-click TallyBook in Applications and choose Open, or use System Settings → Privacy & Security → Open Anyway. Apple notarisation is planned.

Can I move my data from Tally?

Yes. Export masters and vouchers from Tally as XML and import them with Alt+O. See the step-by-step guide.

Can several people use one company at the same time?

Not yet. TallyBook is single-user per computer today. You can create users and passwords to control who may do what.
